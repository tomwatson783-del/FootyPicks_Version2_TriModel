Advanced model controls

League-adjusted · advanced settings

League-adjusted expected-goals engine. Its form windows, selection gaps and confidence multiplier are independent of the updated engine.

Save Settings below activates changes. Existing frozen predictions will not be rewritten.

Team-form · advanced configuration

Auto uses Brier score, which measures the accuracy of all three outcome probabilities. If there are too few eligible test matches, Auto falls back to your manual model.

Hybrid prediction foundation

Blend team-first attacking/defensive performance with the original league-normalised estimate. 100% reproduces the existing model; 0% uses only team-first xG. Model Test checks 0–100% in 5% steps.

Historical xG & finishing — automatic

ESPN match summaries are checked automatically for actual historical xG. Where adequate xG is missing, the standard prediction remains unchanged. Model Test evaluates the influence weights and recommends changes only when supported by historical evidence. No imports or manual statistics.

Legacy outcome boundary inputs (superseded by model draw gap)

Predicted goals determine HOME / DRAW / AWAY. Model Test compares these boundaries for outcome accuracy before assessing SELECT precision.

Selection thresholds

Minimum predicted-goals advantage required for SELECT. Predicted outcome comes directly from the signed goal difference and the trained draw band.

DRAW selection

Draws are predicted naturally. Draw selections require both a small xG gap and sufficient draw probability. Confidence remains advisory.

Run Model Test to check whether draw selections are supported.

Confidence scoring — active settings

Confidence weighting and risk limits.

For winner predictions, confidence ceilings rise from 6 at 1× the approved selection gap to 10 at the chosen multiple. These are ceilings, not automatic ratings. Draw confidence additionally requires meaningful calculated draw probability.

Other confidence safeguards, including sample-size and strong-evidence limits, remain in place.
